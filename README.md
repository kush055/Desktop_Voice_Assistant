# 🎙️ Desktop Voice Assistant

A Python-based voice-controlled personal assistant that helps you perform everyday desktop tasks using just your voice. From opening apps to searching the web and getting the latest weather, this assistant is your hands-free productivity companion.

---

##  Features

-  **Speech Recognition** – Understands your voice commands in real time.
-  **Text-to-Speech** – Responds with natural spoken replies.
-  **Internet Tasks** – Google search, open websites, play YouTube videos, and more.
-  **System Tasks** – Open files, launch applications, check time/date.
-  **General Knowledge** – Answers questions using Wikipedia API.
-  **File Handling** – Create or manage files and folders via voice.
-  **Lightweight & Secure** – Optimized for speed and efficiency on desktop environments.

---
##  Tech Stack

- **Language**: Python 3
- **Libraries**:
  - `speech_recognition`
  - `pyttsx3`
  - `pyaudio`
  - `wikipedia`
  - `webbrowser`
  - `datetime`
  - `os`
  - `subprocess`
